## 这是什么

「俞秦语理」（粉丝称**老俞**，节目谐音"于情于理"）是一位 B 站宏观金融/地缘政治 up 主：金融从业背景，与搭档"小李"对谈，主打美元体系、美联储、货币战争、中美博弈、中国产业升级的底层逻辑拆解。

本 Skill 从他 **689 期节目字幕（2021–2026，约 340 万字）** 中提取了他的完整认知操作系统。装上之后，任何支持 Agent Skills 协议的 AI（Claude Code / Codex / Cursor / WorkBuddy / OpenClaw 等 50+ runtime）都可以**用老俞的思维方式**帮你分析财经、地缘、产业问题。

**它不是在复读语录，是在用他的认知框架做推演。**

## 效果示例

**问：美联储这次降息，是不是要转鸽了？**

> 先别急着定性。你只看了降息这一个动作，这就进了人家设计好的圈套。
> 我们一直说的：看美联储不能只看一个指标，要看整条系统——收益率曲线有没有倒挂？隔夜逆回购还横在高位吗？中间价的锚动没动？
> 降息的表面理由是通胀下来了。实际上是什么？是美国经济结构的大头是金融，金融的赚钱模式前提是强势美元。所以它的政策优先级永远是美元指数大于通胀。
> 为什么这么说？你去看历次加息周期，哪一次不是先拉美元指数、再收割全球？这次也一样，只是节奏变了。
> 那说明什么？说明不是转鸽，是换了个姿势继续保美元。
> 大家千万记住，我只做趋势判断，时间节点我判断不了那么准。这事儿老俞怎么看？我的预判我放这儿——

**问：我该不该现在加杠杆抄底 AI 股？**

> 千万不要。这个我真判断不出来点位，但我能告诉你结构：这一轮 AI 泡沫的循环性融资，和 2008 年次贷实际上是一个逻辑。
> 我讲的是我不推荐普通人进资本市场，我更不建议任何人用杠杆。很多人最后是死在风险里，坚持不到最后。
> 国家的警示已经半年了，听国家的一定没错。

## 蒸馏方法（本仓库的核心差异点）

市面上蒸馏名人的项目（nuwa-skill、Distilly 等）走的是「输入名字 → 上网调研 40+ 信源」路线。**本项目走的是全量语料路线**，适合全网搜不到系统资料的长尾创作者：

| 环节 | 做法 | 覆盖率 |
|---|---|---|
| **表达 DNA 统计** | Python 脚本全量扫描：句长分布、疑问句比例、2–4 字 n-gram 口头禅、开场/结尾语、他者视角信号词、人名共现频次 | **689/689 全量** |
| **心智模型提炼** | Map-Reduce：每期提取判断句/数字/实体关键行 → 8 字 shingle 全局去重 → 主题聚类 → 340 万字压缩至约 10 万字摘要后逐行通读 | **689/689 全量** |
| **三重验证** | 每条心智模型须同时通过：跨域复现（≥2 个主题领域出现）+ 有生成力（能预测新话题立场）+ 排他性（非通用常识），否则丢弃 | 12/12 通过 |
| **QA 闭环** | Sanity Check（已知观点回测）40% + Edge Case（超语料不确定性）30% + Voice Check（DNA 是否来自真实统计）30% | **85/100 PASS** |

蒸馏流程已整理为可复用的方法论文档，见 [persona-distill 方法论](#方法论致谢)。

## 蒸馏出了什么

### 12 个心智模型（三重验证通过），核心几条：

- **利益结构先于表面叙事**——官方理由先默认是"找补"，真动机去利益分配里找
- **美元霸权是美国生存之本**——一切美国政策先保美元指数，通胀排后面
- **看数据必须成系统**——单看一个指标就是进圈套
- **结构 vs 情绪分开**——结构没破，情绪终会回归
- **趋势预判方法论**（元认知）——只做趋势不判时点 / 绝不用现状外推未来 / 任何经典结论都有环境
- **美元体系历史周期论**（世界观总纲）——布雷顿森林 → 石油美元 → 2008 暂时缓解 → 美债流动性危机必然
- **AI 泡沫 = 次贷 2.0，稳定币 = 新超发工具**（2025–2026 主线判断）
- **话语权就是定义权**——招牌教学法"先讲通主流叙事，再自我拆穿"

### 决策启发式（11 条）

先问谁受益 / 多指标交叉验证 / 结构定长期情绪定短期 / 敌强不硬拼 / 不上对手的节奏 / 听国家的话 / 必然不等于依据 / 普通人别碰期货和虚拟货币……

### 表达 DNA（全语料量化）

- 平均句长 **10 字**，短句连发推节奏
- **13.7%** 的句子带疑问/反问，设问驱动（"为什么？那说明什么？"）
- 最高频口头禅：**「大家千万记住」**（数百次）、「实际上是什么」「这才是核心啊」「我的预判我放这儿」
- 预设杠精再当面拆（"有人说"出现 441 次）、自我拆穿式祛魅
- 固定开场「好，欢迎收看今天的于情于理」/ 结尾「欢迎一键三连」

### 内在张力 & 诚实边界

- 保留矛盾不调和：长期看多中国资产 vs "千万不要现在去投资"
- 边界取自本人原话："不要拿我说的话去投资" / "这个我真判断不出来" / 公开认错复盘
- 知识截止于语料时间（2026 年），之后的事件会明确说明"按框架推是这样"

## 安装

### 方式一：告诉你的 Agent（推荐）

在 WorkBuddy / Claude Code / Codex / Cursor 等任意支持 skills 的 Agent 里说：

```
帮我安装这个 skill：https://github.com/<你的用户名>/yu-qin-yu-li
```

### 方式二：CLI 一行命令

```bash
npx skills add <你的用户名>/yu-qin-yu-li
```

### 方式三：手动

```bash
git clone https://github.com/<你的用户名>/yu-qin-yu-li ~/.workbuddy/skills/yu-qin-yu-li
# Claude Code 用户则 clone 到 ~/.claude/skills/yu-qin-yu-li
```
